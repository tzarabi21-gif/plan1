# دیجی ماز — نسخه آنلاین (سایت + API + پنل مدیریت)

سایت شما از حالت «فایل استاتیک با localStorage» به یک **سایت آنلاین واقعی** تبدیل شد:
- بک‌اند Node.js با API
- پنل `admin.html` با لاگین واقعی و اتصال به API — تغییرات بلافاصله در همه صفحات اعمال می‌شود
- صفحات `index / schedule / progress / contact / profile` به API وصل‌اند + حالت آفلاین (fallback روی localStorage)
- **جدید**: صفحه پروفایل با مدیریت چند برنامه مطالعاتی (تب‌مانند گوگل)، ویرایش/حذف/افزودن جلسات، تودو لیست روزانه، و واکنش‌گرا برای موبایل/تبلت/دسکتاپ

## ساختار

```
digimaz-site/
├── public/
│   ├── index.html      # خانه (آمار + تنظیمات از سرور)
│   ├── schedule.html   # برنامه مطالعاتی (سینک پیشرفت + جلسات مدیر)
│   ├── progress.html   # پیشرفت (خواندن از سرور)
│   ├── contact.html    # تماس (ارسال پیام به سرور)
│   ├── admin.html      # ★ داشبورد مدیریت آنلاین
│   └── api.js          # کتابخانه مشترک اتصال به API
├── backend/
│   ├── server.js       # سرور Express + دیتابیس JSON
│   └── package.json
├── Dockerfile
├── render.yaml
└── README.md
```

## API (خلاصه)

| متد | مسیر | توضیح |
|---|---|---|
| POST | `/api/auth/login` | ورود مدیر `{password}` → `{token}` |
| GET | `/api/config` | تنظیمات سایت/تماس/دروس (عمومی) |
| GET | `/api/sessions` | جلسات ویژه مدیر (عمومی) |
| GET/PUT | `/api/progress` | پیشرفت (عمومی) |
| POST | `/api/messages` | ثبت پیام تماس (عمومی) |
| GET/DELETE | `/api/admin/messages` | مدیریت پیام‌ها (توکن لازم) |
| POST/PUT/DELETE | `/api/admin/sessions` | مدیریت جلسات (توکن لازم) |
| PUT | `/api/admin/config/:section` | ویرایش `site/contact/settings/subjects` (توکن لازم) |
| GET | `/api/admin/export` | خروجی کل دیتابیس (توکن لازم) |

هدر احراز هویت مدیر: `x-admin-token: <token>`

## آنلاین کردن (۳ روش)

### روش ۱ — Render (پیشنهادی، رایگان) ⭐
1. پوشه `digimaz-site` را در یک ریپوی گیت‌هاب بگذار.
2. در [render.com](https://render.com) → New → Web Service → ریپو را انتخاب کن.
3. Render فایل `render.yaml`/`Dockerfile` را خودش تشخیص می‌دهد.
4. در Environment مقدار `ADMIN_PASSWORD` را یک رمز قوی بگذار.
5. بعد از Deploy آدرس مثل `https://digimaz.onrender.com` را می‌گیری — همان آدرس سایت آنلاین توست.

### روش ۲ — VPS (اوبونتو)
```bash
# روی سرور:
git clone <repo> && cd digimaz-site/backend && npm install
ADMIN_PASSWORD=یک‌رمز‌قوی PORT=3000 node server.js
# با nginx reverse proxy به دامنه وصل کن + certbot برای HTTPS
```

### روش ۳ — Docker
```bash
docker build -t digimaz .
docker run -e ADMIN_PASSWORD=یک‌رمز‌قوی -p 3000:3000 digimaz
```

## پنل مدیریت — قابلیت‌ها

- 📊 **داشبورد**: پیشرفت کل، تکمیل‌شده، پیام‌ها، روز تا آزمون + نمودار دروس + آخرین پیام‌ها (رفرش هر ۱۰ ثانیه)
- 🏠 **اطلاعات سایت**: نام آزمون، تاریخ آزمون، برند، لوگو، توضیح hero، رنگ‌های اصلی — اعمال فوری در همه صفحات
- 📞 **اطلاعات تماس**: ایمیل/تلگرام/ساعات + Formspree (اختیاری؛ اگر خالی باشد پیام‌ها در همین سرور ذخیره می‌شوند)
- 📅 **جلسات ویژه**: افزودن/حذف جلسه (درس، روز ۱–۱۴، ساعت، نوع) — در schedule.html نمایش داده می‌شود
- 📚 **دروس و رنگ‌ها**: رنگ و تعداد هر درس
- ✉️ **پیام‌ها**: مشاهده/حذف تکی و گروهی
- 📈 **پیشرفت**: خلاصه + به تفکیک درس + یادداشت‌های دانش‌آموز
- ⚙️ **تنظیمات**: نمایش کنتداون/آمار زنده + خروجی JSON کل دیتابیس

## امنیت
- حتماً `ADMIN_PASSWORD` پیش‌فرض (`admin1403`) را روی سرور عوض کن.
- توکن مدیر در `sessionStorage` مرورگر نگه‌داری می‌شود (با بستن تب پاک می‌شود).
- برای production حتماً HTTPS فعال کن (Render خودش HTTPS می‌دهد).

## نکته مهم درباره «پیشرفت هر دانش‌آموز»
در نسخه فعلی، پیشرفت به‌صورت **سراسری** روی سرور ذخیره می‌شود (مناسب استفاده تک‌نفره/خانوادگی).
اگر خواستی هر دانش‌آموز اکانت جدا و پیشرفت جدا داشته باشد، قدم بعدی اضافه کردن «لاگین دانش‌آموز + دیتابیس چندکاربره» است — بگو تا اضافه کنم.

## 🎓 حساب دانش‌آموز (جدید در نسخه ۲)

- صفحه `login.html`: ثبت‌نام (نام + نام کاربری + رمز) و ورود
- هر دانش‌آموز **پیشرفت، تیک‌ها و یادداشت‌های جداگانه** دارد (`/api/student/progress` با توکن خودش)
- بدون ورود هم سایت کار می‌کند (حالت مهمان روی همین دستگاه)، ولی برای ذخیره جداگانه باید وارد شود
- مدیر در پنل `admin.html` → بخش **دانش‌آموزان**: لیست + درصد هر نفر، ساخت حساب دستی، فعال/غیرفعال، ریست پیشرفت، حذف
- تنظیم `allowRegister` در بخش تنظیمات: اگر خاموش باشد فقط مدیر حساب می‌سازد

| متد | مسیر | توضیح |
|---|---|---|
| POST | `/api/student/register` | ثبت‌نام `{name, username, password}` |
| POST | `/api/student/login` | ورود دانش‌آموز |
| GET | `/api/student/me` | اطلاعات حساب (توکن لازم) |
| GET/PUT | `/api/student/progress` | پیشرفت شخصی (توکن لازم) |
| GET | `/api/student/stats` | آمار شخصی (توکن لازم) |
| GET/POST/PUT/DELETE | `/api/admin/students` | مدیریت دانش‌آموزان (توکن مدیر) |
